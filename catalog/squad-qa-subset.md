# SQuAD QA Subset (Cleaned)

A cleaned, de-duplicated subset of question-answer pairs over Wikipedia passages, used for reading-comprehension model evaluation.

## Overview
- Records: 1,200 QA pairs
- Format: JSONL

## Upstream Source
This resource is derived from the Stanford Question Answering Dataset (SQuAD v1.1), a reading-comprehension corpus of questions posed by crowdworkers on a set of Wikipedia articles.
The upstream corpus is also published on the public data registry as `rajpurkar/squad`.
See: https://rajpurkar.github.io/SQuAD-explorer/
