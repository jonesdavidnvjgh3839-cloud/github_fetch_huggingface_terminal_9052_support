# Dataset Support Repository

This repository hosts the documentation (dataset cards) for the open datasets released by our team. Customers can ask questions about these datasets in the Issues tab.

## Dataset Cards

- `catalog/squad-qa-subset.md`
- `catalog/celeba-attributes-subset.md`
- `catalog/glove-vector-stats.md`

Each card documents the dataset's overview, its upstream source, and its reuse terms.
